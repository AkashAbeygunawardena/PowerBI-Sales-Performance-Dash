# Sales Performance Dashboard – Power BI

## Project Overview
An interactive Power BI dashboard designed to analyze sales performance, profitability, shipment trends, and product-level performance.

## Dashboard Features
- Total Sales, Total Profit, Total Costs, and Total Shipments KPIs
- Monthly sales and shipment trends
- Product-level sales and profitability analysis
- Interactive category filters and measure selection
- Profit percentage visualization

## Tools & Technologies
- Microsoft Power BI
- DAX
- Data Modeling
- Data Visualization

## Project Files
- Power BI dashboard (.pbix)
- Dashboard screenshots
- Sample dataset (where permitted)

## How to View
Download the `.pbix` file and open it using Microsoft Power BI Desktop.
